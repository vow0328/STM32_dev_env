## 延伸学习

本仓库只解决 STM32 开发环境的搭建与原理。如果还不确定要不要走嵌入式这条路、不知道该学什么、按什么顺序学，可以配合下面这份学习指南使用：

- [嵌入式学习指南](https://github.com/vow0328/embedded-learning-guide)

它把嵌入式、电控行业的主要岗位方向、技能地图和学习顺序整理成一份可查阅的路线图，覆盖编程与软件基础、MCU 与体系结构、嵌入式软件工程、实时操作系统、控制与算法、电机与执行器、通信与物联网、嵌入式 Linux、FPGA、硬件电路与 PCB、工具仪器、工程交付等十几个方向，共七十余篇内容。每篇开头都会列出前置知识、掌握标准、对应岗位和练手建议，适合按需查阅，不必从头读到尾。
